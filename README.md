## 📌 Featured Projects

### 💼 [AI Career Copilot](https://github.com/SathwikReddy-Bushireddy/ai-career-copilot) · [Live Demo](https://ai-career-copilot-sathwik-reddy.streamlit.app/)
An AI resume analyzer and interview prep dashboard. It scores resumes against ATS standards, matches them to job descriptions, rewrites bullets using Google's X-Y-Z formula, generates 20+ mock interview questions, and includes a RAG chatbot that answers from your CV with source citations.
`Python` `Streamlit` `LangChain` `Gemini` `FAISS` `Plotly`

### 📈 [FinPilot AI](https://github.com/SathwikReddy-Bushireddy/finpilot-ai) · [Live Demo](https://finpilot-ai-sathwik-reddy.streamlit.app/)
A financial assistant built on a LangGraph workflow. It fetches live stock, crypto, currency and news data through tool calling, and includes a RAG-based PDF analyzer that summarizes annual reports and analyzes risk, growth and profitability.
`Python` `LangGraph` `LangChain` `Gemini 2.5 Flash` `FAISS` `Streamlit`

### 🏦 [Banking System API](https://github.com/SathwikReddy-Bushireddy/banking-system-api)
A REST backend for core banking: deposits, withdrawals, transfers and transaction history, plus admin controls to create, block and unblock accounts. It uses a layered architecture, BCrypt-hashed PINs, ACID-safe transactions and global exception handling.
`Java 17` `Spring Boot 3` `JPA/Hibernate` `MySQL` `Maven`

### 📊 [Retail Sales Analytics Dashboard](https://github.com/SathwikReddy-Bushireddy/retail-sales-dashboard)
An interactive Power BI dashboard tracking sales, profit, orders, customers and profit margin across regions, categories and segments, with monthly trend analysis and filters. Data was cleaned in Power Query and KPIs were built with DAX.
`Power BI` `DAX` `Power Query` `Excel`

### 🎮 [Tic Tac Toe](https://github.com/SathwikReddy-Bushireddy/Tic-Tac-Toe)
A two-player command-line Tic Tac Toe game in Java.
`Java`
